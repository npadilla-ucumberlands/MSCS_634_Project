# Student Performance Analysis Using Machine Learning

## Overview
This project analyzes student performance using machine learning techniques to identify patterns and predict academic outcomes. The analysis includes regression, classification, clustering, and association rule mining.

## Dataset
The dataset used is the UCI Student Performance dataset, which contains demographic, behavioral, and academic attributes such as study time, absences, and previous grades.

## Objectives
- Analyze factors affecting student performance
- Predict final grades using regression models
- Classify students into performance categories
- Identify patterns and clusters in the data

## Methods Used
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Regression (Linear Regression, Ridge Regression)
- Classification (Decision Tree, K-Nearest Neighbors)
- Clustering (K-Means)
- Association Rule Mining (Apriori Algorithm)

## Key Findings
- Early grades (G1 and G2) strongly predict final performance (G3)
- Increased study time improves academic outcomes
- Higher absenteeism is associated with lower performance
- Classification models achieved approximately 83% accuracy
- Clustering revealed distinct student performance groups
